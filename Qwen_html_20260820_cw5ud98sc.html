The Content Manager didn't load

Open the browser console (F12 → Console) and look for a red error. Most common causes:

  1. Site deployed by drag & drop — the git-gateway backend only works when the site is connected to GitHub. Re-deploy from Git.
  2. Netlify Identity / Git Gateway not enabled — Netlify → Site configuration → Identity → Enable; then Identity → Services → Git Gateway → Enable; then Identity → Invite users → add your email.
  3. admin/config.yml missing or invalid YAML — the file must exist and parse cleanly.
  4. unpkg.com blocked — a firewall or ad-blocker may be blocking the CMS script. Try another browser/network.
