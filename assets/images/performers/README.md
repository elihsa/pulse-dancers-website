# Performer Photos

## Naming Convention
- Use performer's first name or stage name
- Lowercase, no spaces, use hyphens for multiple words
- Format: JPG or PNG
- Examples: `thunder.jpg`, `john-doe.jpg`, `mike.jpg`

## Photo Specifications
- Format: JPG or PNG
- Dimensions: 400x500px (portrait) recommended
- File size: Under 500KB
- Professional headshots or action shots

## How to Add New Performer

1. Upload photo to this folder
2. Rename following convention above
3. Update Google Sheet "DANCERS" tab with:
   - Name
   - Bio
   - Specialties
   - Photo path: `assets/images/performers/[name].jpg`
   - Active: TRUE
4. Save sheet - performer appears on site automatically!

## Logo and Header Images

If you have the old site's logo and header images (Pulse logo with heartbeat/EKG line, "Male Revue INTERNATIONAL" header, "South Africa's Most Desired Men" tagline), place them here:

- `/assets/images/logo.png` or `/assets/images/logo.jpg` - Main Pulse logo
- `/assets/images/header-text.png` - Header text image (if separate)
- `/assets/images/tagline.png` - Tagline image (if separate)

### Logo Requirements
- Transparent background (PNG preferred)
- High resolution (at least 300px height)
- Should include the Pulse branding with heartbeat/EKG line

Once logo files are added, the website will automatically display them in the header navigation.
